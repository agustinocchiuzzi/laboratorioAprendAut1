# Datos

- `raw/futbol_uruguayo.zip`: dataset original provisto por el curso. No editar.
- `processed/`: salida de `make clean-data`. Se regenera y no se versiona.
- `legacy/`: transformaciones manuales antiguas, excluidas del pipeline.

La corrida debe comenzar siempre desde el ZIP original para cumplir el requisito
de solucion autocontenida.

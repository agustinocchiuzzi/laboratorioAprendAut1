# Informe

`main.tex` es un esqueleto IEEE sin resultados inventados. Para completarlo:

1. ejecutar `make experiment-full`;
2. seleccionar tablas y figuras relevantes de `results/`;
3. escribir el analisis, no solo enumerar metricas;
4. incluir limitaciones y declaracion de uso de IA;
5. compilar y verificar que el PDF tenga como maximo cinco paginas.

Si el equipo docente provee una plantilla IEEE especifica, esa plantilla tiene
prioridad sobre este esqueleto.
